Connect your grading website

The Chrome extension reads supported answer images and carries out website actions requested by Suhuang Scroll. Install it alongside a compatible local program.

Install

Use the Chrome Web Store listing when available. Otherwise download the matching Bridge archive from Releases, extract it, open chrome://extensions, enable Developer mode and choose “Load unpacked”.

Use the sidebar

Open your grading page, then open the extension. The sidebar guides you through choosing a marking guide and website, checking the connection and controlling the run. “Recheck” refreshes the current page and available Specs. Developer tools are separate from everyday controls.

Data and new websites

Read the data notice before allowing access. Answer images can be sent by the local program to your chosen AI provider. See the privacy policy.

If your website is missing, use the sidebar’s new-website guide with your local AI Agent. Keeping the extension enabled does not automatically grant it access to every website.
