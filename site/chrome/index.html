Suhuang Scroll

Chrome Bridge

Install the Suhuang Scroll Bridge from the Chrome Web Store when the listing is available. It is the browser-side execution boundary and works with the separately installed local Runtime.

Search the Chrome Web Store

If the listing is not yet visible in your region, use the matching GitHub Release archive for a controlled unpacked test. Do not mix the extension version with a different Runtime release.

Consent and permissions

The extension shows a data notice before reading a supported grading page. It does not send cookies or browser credentials to Suhuang servers. Score writeback and submission remain explicit operator actions.
