Privacy policy

Last updated: 2026-08-13

Local-first processing

The Runtime stores configuration, question specs, run records, OCR text, and model outputs on the operator's computer according to local configuration. The Plugin and Chrome Bridge do not include analytics, advertising, or telemetry by default.

Browser data

Before the first grading action, the Chrome Bridge shows a data notice and requires affirmative operator consent. Until consent is granted, it does not read answer images or page context, send grading-page heartbeats, or start its page-image observer. After consent, it can read page context and answer images when an operator invokes a supported workflow. It does not transmit browser cookies, passwords, or credentials to Suhuang Scroll servers. Revoking consent stops page observation, blocks further browser actions, and asks the local Runtime to stop an active automation run.

Vision providers

If the operator configures a third-party vision provider, the local Runtime may send captured answer inputs to that provider to produce a grading result. The provider's own privacy policy, retention terms, and regional controls apply. The Codex Plugin does not proxy those model requests.

Optional hosted relay

When enabled, the hosted MCP relay receives tool arguments and transient structured results needed to route a request to the paired local Runtime. The reference control plane keeps this queue in memory and does not send it to a model. A deployment operator is responsible for authentication, retention, logs, and regional controls.

Questions and deletion requests

Contact the monitored support channel listed on the support page. Do not include student data, browser profiles, cookies, or API keys in public requests.
