Agent-assisted grading Runtime

A local-first Runtime, Codex Plugin, and Chrome Bridge for operator-reviewed grading workflows. Specs, decisions, and run events stay under explicit contracts; browser execution remains a separate adapter layer.

Documentation Privacy Terms Support

How the pieces fit

  • The Python Runtime owns grading contracts, model calls, and run state.
  • The Codex Plugin exposes safe inspection and preparation tools.
  • The Chrome Bridge reads supported grading pages and performs explicitly confirmed adapter actions.
  • The operator reviews grading decisions before any score writeback or submission.

The public release does not include browser cookies, student records, or model credentials.
