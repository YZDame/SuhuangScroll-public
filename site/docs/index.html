Getting started

Install the matching local program and Chrome extension. You do not need Python, Node.js or Rust to use a native release.

1. Connect your tools

  1. Download the package for your system from Releases. The current Windows package targets x64.
  2. Follow the release installation instructions, then run suhuang setup to configure your AI service and suhuang doctor to check the installation.
  3. Install the Chrome Bridge, open your grading website and sign in.
  4. Run suhuang for the TUI, or use the separately installed Suhuang Scroll plugin in DeepSeek Harness.

2. Let your AI prepare the marking guide

Upload your existing question, answer and marking guide to your AI client. Ask it to use suhuang-spec to produce a Spec Markdown file. Review the scoring rules before using it.

In the DeepSeek Harness plugin, choose “Import grading Spec (.md)”. Import validates and saves the file locally; it does not begin grading. Rename the file if a Spec with the same name already exists. In the TUI, use /spec to select it.

3. Check, then grade

Confirm the website, question, marking guide and model. Check a small sample first. Starting a real run can write and submit grades according to the configured workflow; review the confirmation carefully. Pause when you need to inspect a result.

Useful TUI commands

  • /spec — choose the marking guide.
  • /adapter — choose the grading website.
  • /start, /pause, /resume, /stop — control the run.
  • /guide — preparation and new-website guidance.
  • /hints off — hide Chinese command hints; /hints on restores them. The preference is saved locally.

A new grading website?

Ask your local Agent to use suhuang-adapter with the website URL. Keep the extension enabled. The Agent needs editable adapter sources and build tools. It must first check whether its browser tools or the extension can access the page; a new domain can require extension permissions and a reload. It should create a disabled adapter and pass healthcheck and synthetic dry-run checks before you choose to enable it. Do not use real student answers or submit scores while developing it.

Optional Codex and remote Agent connections

The Codex Plugin provides Skills, diagnostics, preparation and manual-confirmation controls. Install it from the published plugin directory or marketplace instructions for your release. Hosted MCP is optional and connects a remote Agent to a paired local Runtime Agent. It is not required for local TUI use.

The public Codex Plugin keeps score writeback and website submission behind an additional local operator confirmation.
