Documentation

Install the local Runtime and Chrome Bridge separately. The Codex Plugin provides Skills, safe inspection/preparation tools, and explicitly confirmed manual-confirmation run controls; it does not silently start grading or enable automatic submission.

Release components

  • Native Runtime package: CLI, Python backend, and Rust TUI.
  • Codex Plugin package: Skills, local MCP bridge, and optional app wiring.
  • Chrome Web Store package: Side Panel and site adapters.
  • Hosted MCP control plane: HTTPS relay to a user-owned local Runtime Agent.
  • Review fixture: a local synthetic page for extension healthcheck and dry-run verification.

Safety boundary

The public Plugin surface is limited to diagnostics, contracts, statistics summaries, dry preparation, and manual-confirmation run control. Score writeback and website submission stay behind a second operator confirmation in the local browser workflow.
