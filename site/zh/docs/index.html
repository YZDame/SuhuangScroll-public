苏黄共阅 · Suhuang Scroll

从第一次试评开始

安装配套的主程序和 Chrome 扩展。使用原生发布包无需安装 Python、Node.js 或 Rust。

1. 连接你的工具

  1. 从发布页下载对应系统的软件包。当前 Windows 软件包面向 x64。
  2. 按版本说明安装，运行 suhuang setup 配置 AI 服务，再用 suhuang doctor 检查安装。
  3. 安装 Chrome 扩展，打开阅卷网站并登录。
  4. 运行 suhuang 打开 TUI，或使用单独安装的 DeepSeek Harness 苏黄共阅插件。

2. 让 AI 整理评分标准

在 AI 客户端中上传已有题目、参考答案和评分细则，让 AI 使用 suhuang-spec 生成 Spec Markdown。使用前检查评分规则。

在 DeepSeek Harness 插件中点击“导入评分标准（.md）”。导入只校验并保存在本机，不会开始阅卷；同名文件不会覆盖，请重命名后导入。TUI 中用 /spec 选择文件。

3. 先试评，再开始

确认网站、题目、评分标准和模型，先检查少量答卷。真实阅卷可能按当前流程写入并提交成绩，请仔细阅读确认提示。需要检查结果时，先暂停。

TUI 常用命令

  • /spec：选择评分标准。
  • /adapter：选择阅卷网站。
  • /start、/pause、/resume、/stop：开始、暂停、继续、结束。
  • /guide：查看准备评分标准和新网站适配指引。
  • /hints off：隐藏中文注释；/hints on：恢复。偏好会保存在本机。

遇到新阅卷网站？

把网站地址告诉本地 AI Agent，让它使用 suhuang-adapter。保持扩展开启，先让 Agent 确认有可编辑源码和构建工具，再检查浏览器工具或扩展能访问该网站；新域名可能需要新增扩展权限并重新加载。让 Agent 创建禁用态 adapter，通过健康检查和模拟页面 dry-run 后，再由你决定是否启用。适配开发过程中不要读取真实学生答卷、写分或提交。

可选的 Codex 与远程 Agent 连接

Codex 插件提供技能、诊断、准备和人工确认控制。按对应版本的插件目录或市场说明安装即可。Hosted MCP 用于远程 Agent 连接已配对的本地 Runtime Agent，本地 TUI 使用不需要它。

公开 Codex 插件的写分和网站提交还需要本地操作者再次确认。
