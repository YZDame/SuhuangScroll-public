隐私政策

中文说明更新：2026-10-11

本地优先处理

Runtime 根据本地配置，在操作者电脑上保存设置、评分标准、阅卷记录、OCR 文本和模型输出。插件和 Chrome 扩展默认不包含分析、广告或遥测。

浏览器数据

首次阅卷操作前，扩展显示数据说明并要求明确同意。未同意时，不读取答题图片或页面上下文，不发送阅卷页面心跳，也不启动图片观察。授权后，操作者调用受支持的流程时可以读取页面上下文和答题图片。扩展不把 Cookie、密码或浏览器凭据发送给苏黄共阅服务器。撤回同意会停止页面观察、阻止后续浏览器操作，并请求本地 Runtime 停止正在运行的自动阅卷。

AI 服务商

配置第三方视觉模型后，本地 Runtime 可能把答题输入发送给该服务商以生成评分结果。其隐私、数据保留和地区政策适用。Codex 插件不代理这些模型请求。

可选远程中转

启用 Hosted MCP 后，中转服务接收用于路由到已配对本地 Runtime 的工具参数和临时结构化结果。参考控制服务把队列保存在内存中，不将其发送给模型。实际部署者负责认证、保留期限、日志和地区控制。

疑问和删除请求

请使用支持页面列出的渠道。不要在公开请求中包含学生数据、浏览器配置、Cookie 或 API Key。
