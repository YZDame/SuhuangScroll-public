# Suhuang Scroll Plugin Terms

Last updated: 2026-08-12

Suhuang Scroll is provided as an operator-controlled local grading Runtime and
Codex Plugin. The operator is responsible for configuring a permitted model
provider, complying with applicable education/privacy rules, reviewing grading
decisions, and confirming any score writeback or submission.

The Plugin's inspection and preparation tools do not guarantee that a local
Runtime, browser adapter, hosted relay, or third-party model provider is
available. Adapter and model outputs are suggestions for review, not an
automatic determination of a student's final result. The operator must keep
credentials and student data out of public issues and must follow the selected
provider's terms. If the hosted relay is enabled, the operator accepts its
configured transient command-routing boundary and should use a deployment with
appropriate authentication, retention, and regional controls.

Before publishing a public listing, replace this repository document link with
the current canonical terms URL if the hosting location or support contact
changes.
