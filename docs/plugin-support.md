# Suhuang Scroll Plugin Support

Use the repository issue tracker at
<https://github.com/YZDame/SuhuangScroll-public/issues> for reproducible bugs and
release-specific questions. Include the Plugin version, Runtime version, and
operating system,
the output of `suhuang doctor --format json` after removing paths, identifiers,
and secrets.

Do not attach cookies, browser profiles, student answer images, API keys, or
private run records to a public issue.

Before a public Codex Plugin submission, publish this page and the privacy
notice at stable HTTPS URLs and confirm that the issue tracker is monitored.
