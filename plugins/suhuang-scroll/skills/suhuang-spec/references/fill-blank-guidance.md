# Fill-Blank Spec Guidance

Use `type: fill_blank` and include blank-level answers and scores. Make each blank independently executable.

Rules should cover:

- accepted equivalent forms for each blank
- radicals, fractions, intervals, units, and ordering
- partially correct multi-expression blanks
- empty, illegible, or OCR-uncertain blanks
- manual-review thresholds

Prefer fixed language:

- "本空答案为 A 或与 A 等价的表达，给 X 分。"
- "若写成未化简但数学等价的形式，给满分。"
- "若只写出其中一个必要表达，固定给 Y 分。"
- "空白、无法辨认、或 OCR 置信度不足时，本空 0 分并建议人工复核。"
